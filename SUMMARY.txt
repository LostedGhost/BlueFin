┌─ 🏗️  ARCHITECTURE ──────────────────────────────────────────────────────────────┐
│                                                                                 │
│ FLUX EMAIL:                                                                    │
│   Hôte → POST /api/v1/host/properties/{id}/submit                             │
│      ↓                                                                          │
│   Event PropertySubmittedForApproval                                           │
│      ↓                                                                          │
│   Listener SendAdminPropertyNotification                                       │
│      ↓                                                                          │
│   Pour chaque admin:                                                            │
│     ✓ Créer AdminNotification en DB                                            │
│     ✓ Envoyer WhatsApp (si enabled)                                            │
│     ✓ Envoyer Email HTML (si enabled)                                          │
│      ↓                                                                          │
│   Admin reçoit email avec image et lien d'action                               │
│                                                                                 │
│ FLUX IMAGES:                                                                   │
│   Frontend upload image                                                        │
│      ↓                                                                          │
│   Storage::store('properties/{id}', 'public')                                  │
│      ↓                                                                          │
│   PropertyPhoto créé avec:                                                     │
│     - photo_path: 'properties/8/...jpg'                                        │
│     - photo_url: '/storage/properties/8/...jpg'                                │
│      ↓                                                                          │
│   API retourne photo_url                                                       │
│      ↓                                                                          │
│   Frontend utilise: http://localhost:8000/storage/properties/8/...jpg          │
│      ↓                                                                          │
│   Serveur (via lien symbolique) retourne fichier                               │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
